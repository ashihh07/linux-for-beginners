# Contributing to Linux for Beginners

Thank you for taking the time
to contribute. Here is how you can help:

## Reporting Errors

If you find a typo, a broken command, or anything
that seems wrong:

1. Open an Issue
2. Include the chapter number and section
3. Describe what is wrong and what the correct version should be

## Suggesting Improvements

Open an Issue describing your suggestion
before opening a Pull Request. Small fixes (typos) can go straight to a PR.

## Questions

Use GitHub Discussions for questions -- not Issues.
Issues are for bugs and improvements only.

## Code of Conduct

Be kind. This is a beginner-friendly project.
Answers that make newcomers feel stupid are not welcome.
